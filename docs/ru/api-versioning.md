# Версионирование API

InteractiveCommons использует версионирование API для обеспечения обратной совместимости при обновлениях.

---

## Зачем нужно версионирование?

По мере развития InteractiveCommons добавляются новые функции, а существующие API могут изменяться.
Версионирование позволяет контент-пакам продолжать использовать старые API, при желании
переходя на новые версии.

---

## Как это работает

Все require включают версию API в путь, например:
```lua
require("intcom:api/v1/components/boat")
```

## Гарантия совместимости

- **v1** останется доступной и функциональной.
- Контент-паки, использующие `v1`, не сломаются при выходе новых версий.
- Исправления ошибок могут быть перенесены в `v1` в критических случаях.
- Новые функции добавляются только в последнюю версию.

## Последняя версия

На момент последнего обновления это версия v1
