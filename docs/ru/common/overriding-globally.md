# 03. Глобальное переопределение поведения по умолчанию

Контент-паки могут глобально переопределять поведение функций лодки по умолчанию.
Это влияет на **все** лодки в игре, независимо от того, из какого пакета они происходят.

Это полезно, когда вы хотите:
- Добавить глобальные механики (например, все лодки воспроизводят звук при использовании)
- Исправить ошибки или изменить поведение по умолчанию во всей игре

---

## Как это работает

1. Получите компонент лодки по умолчанию
2. Получите доступ к внутренней таблице функций `comp`.
3. Замените любую функцию своей собственной реализацией.
4. Сохраните ссылку на исходную функцию, если вам нужно её вызвать.

### Переопределение параметров по умолчанию

1. Получите компонент лодки по умолчанию
2. Измените `default_param` по своему усмотрению.

---

## Пример: Глобальное переопределение `on_used`

Создайте `scripts/world.lua` в вашем пакете контента:

```lua
local boat_comp = require("intcom:api/v1/components/boat")
local comp = boat_comp.comp

function on_world_open()
	local super_on_used = comp.on_used

	comp.default_params.max_speed = 15
	comp.on_used = function(self, pid)
		console.chat("глобальная переопределённая функция использована!")
		super_on_used(self, pid)
	end
end
```

## Важные замечания

- Глобальные переопределения должны применяться **при открытии мира** (`on_world_open`), а не на верхнем уровне файла.
- Всегда сохраняйте ссылку на исходную функцию перед её переопределением.
- Глобальные переопределения влияют на **все** сущности этого типа, включая те, которые происходят из других пакетов.
