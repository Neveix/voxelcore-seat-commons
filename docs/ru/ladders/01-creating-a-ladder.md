# 01. Создание лестницы

Чтобы добавить лестницу в ваш контент-пак, вам нужно добавить тег `intcom:ladder`
в определение вашего блока.

Смотрите [Руководство по созданию сущности](../common/creating-an-entity.md) для общего объяснения переопределений.

---

## Пример: Минимальная лестница

**`blocks/ladder.json`:**

```json
{
  "model": "custom",
  "model-name": "ladder",
  "rotation": "pane",
  "caption": "ladder",
  "hitbox": [
    0.125,
    0,
    0,
    0.75,
    1,
    0.125
  ],
  "sky-light-passing": true,
  "solid": false,
  "light-passing": true,
  "tags": [
    "intcom:ladder"
  ]
}
```

**Обязательные поля:**

| Поле | Значение | Описание |
| :--- | :--- | :--- |
| `tags` | `["intcom:ladder"]` | Необходимо для идентификации этого блока как лестницы |

---


## Настройка

### Двусторонняя лестница

Просто добавьте тег в поле tags вашей лестницы:
```json
{
  "tags": [
    "intcom:ladder",
    "intcom:double_sided_ladder"
  ]
}
```

### Более глубокая настройка

Чтобы настроить поведение лестницы, создайте файл модуля в вашем контент-паке:

```
modules/intcom/ladder/<имя_вашей_лестницы>.lua
```

`<имя_вашей_лестницы>` должно совпадать с именем, используемым в определении вашего блока.

---

### Переопределение параметров

**Пример `modules/intcom/ladder/ladder.lua`:**

```lua
return {
    linear_damping = 20,
}
```

Все параметры необязательны. Если они опущены, используются значения по умолчанию.

Смотрите раздел [Доступные параметры](#available-parameters) ниже для полного списка.

---

### Переопределение функций

**Пример:**

```lua
local C = {}

---@param super ladder_comp
function C.init(super)
    C.super = super
    C.super_funcs = {
        player_mount = super.player_mount,
    }
    return C
end

function C.player_mount(self)
    C.super_funcs.player_mount(self)
end

C.params = {
    linear_damping = 20,
}

return C.init
```

---

## Доступные функции для переопределения

| Функция | Описание |
| :--- | :--- |
| `on_spawn(self)` | Вызывается при появлении сущности лестницы |
| `on_despawn(self)` | Вызывается при уничтожении сущности лестницы |
| `player_mount(self)` | Вызывается, когда игрок садится на лестницу |
| `player_unmount(self)` | Вызывается, когда игрок слезает с лестницы |
| `player_start_unmount(self)` | Запускает процесс слезания |
| `save_player_body_settings(self)` | Сохраняет настройки физики игрока перед посадкой |
| `load_player_body_settings(self)` | Восстанавливает настройки физики игрока после слезания |
| `move(self, delta)` | Обрабатывает движение лестницы и ввод |
| `check_unmount(self)` | Проверяет, должен ли игрок слезть (например, noclip, полёт) |
| `get_tag_name(self)` | Возвращает тег блока, используемый для идентификации лестницы |
| `on_update(self, tps)` | Вызывается каждый тик |
| `init_step_sounds(self, delta)` | Вызывается в on_spawn. |
| `play_step_sounds(self, delta)` | Вызывается в on_update для воспроизведения звуков шагов |

Для справочных реализаций смотрите `intcom:modules/api/v1/components/ladder.lua`.

## Доступные параметры

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `max_speed_xz` | `number` | `1.5` | Максимальная горизонтальная скорость лазания (обычный режим) |
| `max_speed_xz_cheat` | `number` | `50` | Максимальная горизонтальная скорость лазания (режим читов/быстрый режим) |
| `max_speed_y` | `number` | `2` | Максимальная вертикальная скорость лазания (обычный режим) |
| `max_speed_y_cheat` | `number` | `80` | Максимальная вертикальная скорость лазания (режим читов/быстрый режим) |
| `linear_damping` | `number` | `10` | Демпфирование, применяемое к горизонтальному движению на лестнице |
| `linear_damping_cheat` | `number` | `2` | Горизонтальное демпфирование в режиме читов/быстром режиме |
| `vdamping` | `number` | `0.5` | Вертикальное демпфирование при лазании |
| `vdamping_cheat` | `number` | `0.2` | Вертикальное демпфирование в режиме читов/быстром режиме |
| `vert_acceleration` | `number` | `10` | Вертикальное ускорение при лазании |
| `vert_acceleration_cheat` | `number` | `100` | Вертикальное ускорение в режиме читов/быстром режиме |
| `gravity` | `number` | `0` | Гравитация, применяемая к игроку на лестнице (0 = нет гравитации) |
