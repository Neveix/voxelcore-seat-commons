# 01. Создание сущности

Это руководство описывает общий подход к созданию любого типа сущностей в InteractiveCommons.

---

## Настройка

Чтобы настроить поведение, создайте файл модуля в вашем контент-паке:

```
modules/intcom/<тип_сущности>/<ваше_имя>.lua
```

`<тип_сущности>` — одно из следующих значений: ["boat", "seat", "ladder"]

`<ваше_имя>` должно совпадать с именем, используемым в определении вашей сущности.

Существует два типа переопределений:

1. **Параметры** — простые значения, такие как скорость, смещения позиции и т.д.
2. **Функции** — пользовательская логика для конкретных событий

---

### Переопределение параметров

Верните таблицу с параметрами, которые вы хотите изменить.

**Пример:**

```lua
return {
    max_speed = 10,
    acceleration = 0.07,
}
```

Все параметры необязательны. Если они опущены, используются значения по умолчанию.

Полный список параметров см. в руководстве, специфичном для конкретного типа сущности.

---

### Переопределение функций

Чтобы переопределить функции, верните функцию-инициализатор, которая принимает реализацию по умолчанию.

**Пример:**

```lua
local C = {}

function C.init(super)
    C.super = super
    C.super_funcs = {
        on_used = super.on_used
    }
    return C
end

function C.on_used(self, pid)
    console.chat("переопределено!")
    C.super_funcs.on_used(self, pid)
end

C.params = {
    max_speed = 7,
}

return C.init
```


### Как это работает

- Инициализатор получает таблицу `super`, содержащую реализацию по умолчанию.
- Возвращаемая таблица должна содержать:
  - [необязательно] Переопределённые функции
  - [необязательно] Поле `params` с переопределениями параметров
- Чтобы вызвать родительскую реализацию, сохраните ссылку на исходную функцию
  (например, в `C.super_funcs`) и используйте её позже.

```lua
C.super_funcs = {
    on_used = super.on_used
}
```

> ⚠️ **Предупреждение:** Не вызывайте `C.super.on_used(self, pid)` напрямую внутри переопределённой функции,
> так как это приведёт к **бесконечной рекурсии**. Сохраняйте ссылку отдельно, как показано выше.


- Примечание: все функции, содержащиеся в таблице `C` (компонента), будут использоваться для переопределения.
