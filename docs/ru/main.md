# InteractiveCommons — Документация для разработчиков

**Версия движка:** VoxelCore 0.31.4+

---

## Обзор

InteractiveCommons предоставляет фреймворк для создания **интерактивных сущностей и блоков** в VoxelCore — 
всего, на что игрок может сесть, сесть верхом или взобраться.

Он обрабатывает:

- Физику и движение (для транспортных средств)
- Логику посадки (через RideableAPI)
- Позиционирование игрока и смещения
- Обработку взаимодействий (on_used, on_attacked и т.д.)

Фреймворк построен вокруг **пресетов** — готовых к использованию реализаций для:
- Лодок
- Мебели
- Лестниц

Это библиотечный пакет. Он не добавляет контент сам по себе — 
он предоставляет строительные блоки для использования другими пакетами.

---

## Настройка

Чтобы использовать InteractiveCommons в вашем контент-паке:

- Убедитесь, что [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api) установлен и загружен.


---

## Версионирование API

InteractiveCommons использует версионирование API для обеспечения обратной совместимости.

Все require включают версию API в путь.

Когда выходит новая мажорная версия, старая версия остаётся доступной.
Это позволяет контент-пакам обновляться постепенно, не ломая ничего.

Подробнее см. в разделе [Версионирование API](./api-versioning.md).
