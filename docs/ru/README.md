# InteractiveCommons

Контент-пак для [VoxelCore](https://github.com/MihailRis/voxelcore)

*Примечание: README написано с помощью ИИ.*

---

## Описание

InteractiveCommons предоставляет коллекцию готовых пресетов для **интерактивных сущностей или блоков** в VoxelCore.

Включает пресеты для:

- **Лодок** — водный транспорт с физикой и плавучестью
- **Стульев** — мебель, на которую можно сесть (скамьи, троны и т.д.)
- **Лестниц** — конструкции, по которым можно лазать

Все пресеты построены на:
- [RideableAPI](https://github.com/Neveix/rideable-api) — для логики посадки
- Системе подключаемых компонентов — для лёгкой настройки или переопределения

---

## Установка

1. Скачайте контент-пак.
2. Поместите папку в вашу директорию `content/`.
3. Убедитесь, что установлен [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api).

---

## Для игроков

Этот пак сам по себе не добавляет никаких видимых предметов или механик.
Это библиотека, которую другие контент-паки используют для добавления интерактивных сущностей или блоков.
